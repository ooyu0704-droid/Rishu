# Rishu（履修表サービス）

> **コンテンツが、言語と国境を越えたかけがえのない縁を生み出す世界をつくる**

アニメ・漫画・映画などの視聴済みコンテンツを「履修表」として登録し、他のユーザーと「シンクロ」させることで共通の趣味を持つ人と出会えるプラットフォームです。

---

## ミッション

**コンテンツを共通言語に、世界中のコミュニティの発展を支援する**

日本のアニメ・漫画・映画が世界の共通話題となりつつある今、言語や国境を越えた「共通項」を可視化することで、世界中のファン同士をつなぎます。

---

## サービスの核心：シンクロ機能

自分と相手の視聴コンテンツを比較し、共通する作品（シンクロポイント）を即座に見つけ出す機能です。

```
あなたの履修表  ×  相手の履修表  →  シンクロ率 + 共通作品ハイライト
```

### 特徴

- **非対称シンクロ**：フォローしている相手（有名人・インフルエンサー）の履修表とも、相手が目の前にいなくてもシンクロを確認できます
- **QRコード交換**：コミケ等のリアルイベントでQRコードを交換するだけで、共通コンテンツが一目でわかります
- **言語の壁を越える**：「シンクロ率72%」「進撃の巨人 一致！」という数字・作品名は言語を問わず伝わります

## ターゲットユーザー

| タイプ | 特徴 | 優先度 |
|---|---|---|
| **タイプB：外向型コアオタク** | 趣味仲間を積極的に増やしたい。コミケ等のイベントに積極参加するが、声をかけるきっかけがない | ◎ 最優先 |
| **タイプA：内向型コアオタク** | 語り合える相手を求めているが、自分から動くのは苦手。「同担拒否」リスクを恐れている | ○ 重要 |
| **タイプC：ライトオタク** | 趣味は持っているが、コアな活動には参加しない。口コミ流入層 | △ 将来 |

## プロダクトの設計方針

> **「履修表」は出会いの入口を作るツール。熱量の判断はその先の会話に委ねる。**

「同じ作品を知っている」という共通項だけで、初対面のハードルは劇的に下がります。アプリが熱量まで判断するのではなく、自然なコミュニケーションのきっかけを作ることに特化します。

---

## MVP の定義

> **「コミケ会場で、QRコードを交換するだけで、相手の履修表を確認でき、共通の趣味が一目でわかる」体験を、最速で届ける**

### MVP スコープ（主要機能）

#### 1. 履修表作成機能
- アニメ・漫画・ゲームのコンテンツをキーワード検索して登録
- 外部コンテンツDB（MyAnimeList / AniList API）と連携してサジェスト表示
- 各コンテンツにコメント・評価・視聴進捗を記録
- ジャンルフィルタリング・並び替え対応

#### 2. QRコード生成・読み取り機能
- 自分の履修表URLを含むQRコードをワンタップで全画面表示
- 相手のQRコードをカメラで読み取り、履修表を即時表示
- 屋外・暗い会場でも読み取りやすいサイズで表示

#### 3. シンクロ（共通コンテンツ ハイライト）機能
- 2人の履修表を照合し、共通コンテンツを自動抽出
- 共通作品を最上部に「○作品が一致！」とバッジ形式で強調表示
- 共通でないコンテンツはその下に表示

#### 4. X（Twitter）アカウント連携
- OAuth 2.0 によるX アカウントログイン
- フォロー中ユーザーの中からサービス登録者を検索・フォロー（24時間キャッシュ）

#### 5. チュートリアル
- 初回ログイン時に3ステップで履修表作成を体験
- ジャンル選択 → 作品選択 → 視聴状況登録

#### 6. 定期レコメンド
- 履修表をもとにした新作・未視聴コンテンツの提案

## ユーザーストーリー（POC シナリオ）

**Before（サービス利用前）**
コミケ当日、拓也はひとりで会場を歩きます。同じグッズを持つ人を見かけても声をかけられず、帰り道「今日も誰とも話せなかった」と感じます。

**After（サービス利用後）**
アプリのQRコードを表示して会場を歩く拓也。気になるサークルで「よかったら履修表交換しませんか？」と一言。読み取ると共通作品が一目でわかり、「この作品も見てるんですか！」という会話が自然に始まります。その日のうちにSNSでつながります。

## 成長戦略

### ユーザー獲得ロードマップ

```
B（インフルエンサー） → A（口コミ） → C（広告）
```

### コミケ POC 戦略

1. 有名コスプレイヤー・インフルエンサーが事前に履修表を登録
2. コミケ前に「○○さんとのシンクロを確認しよう」でDL動機を創出
3. 当日、目の前のコスプレイヤーとシンクロを体験 → SNS拡散
4. 非参加者への波及 → 次回イベントへのループ

### 成長ループ

タイプBがサービスを使い始め、イベントでタイプAに「履修表見せてよ」と声をかける → タイプAのスイッチが入り深い交流が生まれる → 「このサービスで仲良くなれた！」体験がSNSで拡散 → タイプCも流入

## グローバル展開の方針

MVP は日本語のみで提供しますが、将来の海外展開を見据えた設計を採用します。

| フェーズ | 対象 | 内容 |
|---|---|---|
| MVP | 国内 | 日本語のみ・コミケPOC |
| Phase 2 | 訪日外国人 | 英語UI追加・多言語コンテンツDB |
| Phase 3 | グローバル | Anime Expo（LA）・Japan Expo（Paris）等での展開 |

日本人ファンと海外ファンのシンクロは、言語を問わず作品タイトルで成立するため、コアバリューはそのまま国際展開できます。

## マネタイズ計画

| フェーズ | モデル | 内容 |
|---|---|---|
| Phase 1 | アフィリエイト | dアニメ・Amazon・チケット誘導 |
| Phase 2 | プレミアムサブスク | 詳細シンクロ分析・公式インフルエンサープラン |
| Phase 3 | B2Bデータ提供 | Crunchyroll・Netflix・出版社向けの視聴インテリジェンス販売 |

本サービスが構築するコンテンツDBとユーザー視聴データは、日本のアニメ・コンテンツ産業が海外市場の需要を把握するための重要なデータソースとなることを目指します。
